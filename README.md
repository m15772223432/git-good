# git-playground

A simple Python calculator project for practicing Git operations.

## Project Structure

```
git-playground/
├── main.py              # Entry point
├── requirements.txt     # Dependencies
├── src/
│   ├── __init__.py
│   └── calculator.py    # Core logic
└── tests/
    ├── __init__.py
    └── test_calculator.py
```

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Test

```bash
pytest tests/
```
